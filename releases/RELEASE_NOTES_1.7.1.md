# WebFile 1.7.1

WebFile 1.7.1 updates the Go compiler to address GO-2026-6859 in `net/http`.

## Changes

- Update the pinned Go compiler from 1.27.3 to 1.27.4.
- Regenerate the matching Go standard-library notice.
- Restore keyboard focus to the New folder button after closing its dialog, including in browsers that do not focus buttons on click.

## Deployment

No configuration migration is required.
