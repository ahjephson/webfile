# WebFile demo screenshot

`webfile-demo.jpg` is an unretouched browser screenshot of the running WebFile development app, captured on 15 November 2026 from the application sources in release 1.9.1 (`4455eae`). It shows the real split-pane interface after copying `Project brief.md` from Projects to Backups. All visible files are fictional fixtures generated by `site/demo.py`.

The original capture is 1280 × 720 pixels. The website scales the image responsively and links to the original file. No application UI, file rows, progress indicators or account labels were drawn over the capture.

To reproduce the environment, build the frontend and development binary in a native Linux workspace, then run the fixture launcher:

```bash
npm --prefix web run build
go -C backend build -o ../dist/webfile-site-demo ./cmd/webfile
python3 site/demo.py --serve
```

The launcher requires Bubblewrap (`bwrap`). It mounts a private account database for the demo process, with the invoking user's real UID/GID named `demo`, and supplies an isolated temporary home. It does not change host accounts or the application's authentication code. Only the freshly generated demo directory and private temporary files are writable inside the mount namespace. The development server binds to `127.0.0.1:8124`, with no personal filesystem roots or existing application state.

In the in-app browser, open `http://127.0.0.1:8124/`, choose Projects, enable split view, navigate the other pane to Backups, choose the Dark theme, and copy the project brief using **Actions → Copy to other pane**. Capture the actual app after the completion notification disappears. Keep the screenshot free of browser chrome and personal data, and review the full-resolution image before replacing the checked-in asset.
